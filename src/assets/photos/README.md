# Produktfotos

Lege hier deine eigenen Fotos ab. Der **Dateiname bestimmt die Position** auf der Website:

| Datei                  | Position                          | Empfohlenes Format          |
| ---------------------- | --------------------------------- | --------------------------- |
| `hero.jpg`             | Großes Bild ganz oben             | Querformat, ≥ 2400 × 1250 px |
| `produkt.jpg`          | Zusatzfoto im Abschnitt „Der Koffer“ | Querformat 16:9, ≥ 2000 px breit |
| `abholung.jpg`         | Statt der schematischen Karte     | ca. 15:16, ≥ 1200 px breit  |

Erlaubte Endungen: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

Beim Build werden automatisch verkleinerte AVIF- und WebP-Versionen erzeugt.
Solange eine Datei fehlt, zeigt die Seite stattdessen eine schematische Zeichnung.
`hero.*` wird außerdem automatisch als Vorschaubild für Social Media (Open Graph) verwendet.
